# JAL PRAVAAH — Geospatial Flood Intelligence & HADR Decision-Support Platform

A national-level, map-first geospatial digital twin for simulating dam-break, sudden water release, natural river blockage, and glacial outburst floods; modeling downstream time-dependent wave propagation; performing spatial loss and damage impact analysis; comparing Smoothed Particle Hydrodynamics (SPH) and Delft3D hydrodynamics; evaluating Sentinel-1 SAR satellite observations; and generating actionable HADR emergency response priority rankings.

---

## Key Features

- **Map-First Web GIS Interface**: 65% interactive map canvas with MapLibre GL JS (3D terrain pitch), deck.gl vector particle rendering, and Carto satellite/dark basemaps.
- **Searchable Indian Study Domains**: Instant search & camera flyTo across Indian dams, rivers, and urban centers (Tehri Dam, Bhagirathi River, Rishikesh, Haridwar, Mullaperiyar Dam, Bhakra Dam, Kosi River, Hirakud Dam).
- **Multi-Engine Hydrodynamic Suite**:
  - **SPH Engine**: 2D Meshless Smoothed Particle Hydrodynamics Navier-Stokes solver evaluating cubic spline kernel density summation ($W(r,h)$) and momentum flux.
  - **Delft3D Adapter**: Adapter for Delft3D-FM curvilinear grids with status detection & executable setup guide.
  - **Deterministic 2D Hydraulic Wave Solver**: Computes Ritter/Froehlich breach outflow hydrographs and 2D wave propagation down DEM terrain elevation profiles.
- **Temporal Simulation Playback**: Interactive timeline scrubber ($0$ to $6$ hours) with Play/Pause, Speed multipliers ($1x, 2x, 5x$), and dynamic color-mapped flood depth legends.
- **What-If Scenario Laboratory**: Multi-scenario creation (Scenario A: 50m breach, Scenario B: 100m breach, Scenario C: 200m breach) with dynamic percentage exposure deltas.
- **HADR Emergency Decision Engine**: Multi-factor priority ranking algorithm scoring downstream settlements by population exposure, flood arrival time, peak depth, hospital density, and road cutoff status.
- **Satellite Observation & Model Validation**: Sentinel-1 SAR change detection module computing Intersection over Union (IoU), Precision, Recall, and F1 Score.
- **GIS Export & Reporting**: One-click download of ESRI Shapefile ZIP (.shp, .shx, .dbf, .prj), KML, GeoJSON, CSV, and ReportLab executive PDF reports.

## Tech Stack

- **Frontend**: SvelteKit / Vite, TypeScript, Tailwind CSS, MapLibre GL JS, deck.gl, Lucide Icons.
- **Backend**: Python 3.11+, FastAPI, Pydantic v2, Uvicorn.
- **Geospatial & Hydrodynamics**: GeoPandas, Shapely, PyProj, PyShp, NumPy, SciPy, ReportLab.

## Installation & Running Locally (Recommended)

Since Python and Node.js are installed on your machine, you can run the system natively in 2 simple terminal windows without needing Docker Desktop:

### Terminal 1: Launch Backend API Server
```powershell
# In project root (c:\programming\projects\Dam Breakers)
.\venv\Scripts\activate
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

### Terminal 2: Launch Frontend Web GIS Application
```powershell
# In project root
cd frontend
npm run dev
```

Open browser at **`http://localhost:5173`**.
